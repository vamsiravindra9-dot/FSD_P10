Part (b) – mongosh CRUD Procedure

Step-by-step interactive execution of the experiment requirements.

Step 1

Switch to Database

USE

Switch the current shell context to the library database.

mongosh
use library
Step 2

Insert Documents (Create)

INSERT

Insert the 3 required documents with title, author, year, and genre.

mongosh
db.books.insertMany([
  { title: "To Kill a Mockingbird", author: "Harper Lee", year: 1960, genre: "Fiction" },
  { title: "1984", author: "George Orwell", year: 1949, genre: "Dystopian" },
  { title: "The Great Gatsby", author: "F. Scott Fitzgerald", year: 1925, genre: "Classic" }
])
Step 3

Find and Query Documents (Read)

FIND

Query all books and find books by author George Orwell.

mongosh
// 3a. Display all books
db.books.find()

// 3b. Find books by specific author
db.books.find({ author: "George Orwell" })
Step 4

Update the Year of a Book (Update)

UPDATE

Update the publication year of 1984 using $set.

mongosh
db.books.updateOne(
  { title: "1984" },
  { $set: { year: 1950, genre: "Dystopian Fiction" } }
)
Step 5

Delete a Book by Title (Delete)

DELETE

Delete The Great Gatsby from the collection.

mongosh
db.books.deleteOne({ title: "The Great Gatsby" })
Step 6

Verify Final Collection State

VERIFY

Inspect the remaining documents in the collection.

mongosh
db.books.find().pretty()
